# Security / Sicherheit

English: Please report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/deckerweb/breakdance-quicknav/security/advisories/new). Do not post exploit details, credentials, or private website data in public issues. This channel also covers the bundled deckerweb Library and Updater. If reporting is not enabled, contact the repository owner through an existing private GitHub channel; do not publish the vulnerability.

Deutsch: Bitte melde Sicherheitslücken vertraulich über [GitHubs private Sicherheitsmeldungen](https://github.com/deckerweb/breakdance-quicknav/security/advisories/new). Veröffentliche keine Exploit-Details, Zugangsdaten oder privaten Website-Daten in Issues. Der Meldeweg gilt auch für die mitgelieferte deckerweb Library und den Updater. Ist er noch nicht aktiviert, verwende einen bestehenden privaten GitHub-Kanal zum Repository-Inhaber; veröffentliche die Lücke nicht.

Include / Bitte angeben: affected versions, reproducible steps, expected impact, and a minimal example without secrets / betroffene Versionen, nachvollziehbare Schritte, Auswirkungen und ein kleines Beispiel ohne Geheimnisse.
