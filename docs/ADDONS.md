# Addons

[Deutsch](ADDONS-de.md)

Breakdance AI 1.2.0 registers the `ai` settings tab. WPSix Exporter 2.0.5 registers `wpsix-exporter`; QuickNav resolves registered menus first and retains the legacy `wpsix_exporter` fallback for older installations. Its administrator/menu permissions remain applicable.

Headspin Copilot, Yabe Webfont, Reading Time Calculator and Breakdance Migration Mode integrations remain. Their current packages will be verified after the first test version. Unknown addons are not removed merely because their package has not yet been supplied. Migration Mode appears when its settings tab is registered.

WPSix Elements 1.0.8 and Image Replacer 1.0.5 have no separate admin settings menu in the supplied packages. QuickNav lists their detected versions without creating a dead shortcut. This verifies QuickNav integration, not every feature of the addon itself.
