# Kompatibilität

[English](COMPATIBILITY.md)

Breakdance QuickNav unterstützt die Familien Breakdance 2.x und 3.x durch Erkennung des tatsächlichen Breakdance-Modus und vorhandener Schnittstellen. Oxygen-Modus ist ausgeschlossen. Die Testmatrix umfasst die gelieferten Pakete 2.8.3 und 3.0.0 RC1. Sie bestätigt weder jede historische 2.x-Version noch eine künftige finale 3.x-Version.

Der Host behält WordPress 6.7 und PHP 7.4 als Mindestanforderungen. Library 0.8.1 benötigt PHP 8.0, Updater 2.1.0 PHP 8.1. Komponenten pausieren bei unpassender Plattform; Host-Navigation und Einstellungen bleiben verwendbar, manuelle Updates möglich. Eine neuere kompatible Library kann bei mehreren Hosts die Auswahl übernehmen. Eine inkompatible ältere gemeinsame Updater-Klasse wird mit einem Einstellungshinweis behandelt.

QuickNav lässt sich ohne Breakdance aktivieren und hält seine Einstellungen erreichbar. Der begrenzte Aktivierungsadapter delegiert andere Plugins an die unveränderte Library-Prüfung. Der zentrale Katalog von Library 0.8.1 beschreibt weiterhin die zuvor veröffentlichte Breakdance-QuickNav-Version; dieser Host schreibt Katalogkarten nicht um. Ein Katalogupdate ist ein eigener Auftrag nach einer freigegebenen stabilen Veröffentlichung.

Grafikvariante B ist ausgewählt. Die vertiefte Prüfung der vier noch nicht gelieferten Addons folgt nach dieser Testversion. Das Snippet ausschließlich für Navigation wird separat aufgrund der ausdrücklichen Projektfreigabe erzeugt. Es besitzt keine Einstellungsseite, keinen Updater und keine Library und darf nicht neben dem Plugin laufen.
