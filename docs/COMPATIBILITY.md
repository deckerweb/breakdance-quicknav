# Compatibility

[Deutsch](COMPATIBILITY-de.md)

Breakdance QuickNav supports the Breakdance 2.x and 3.x families by detecting the actual Breakdance mode and available interfaces. Oxygen mode is excluded. The test matrix covers the supplied 2.8.3 and 3.0.0 RC1 packages. It does not certify every historical 2.x release or a future final 3.x release.

The host retains WordPress 6.7 and PHP 7.4 minimums. Library 0.8.1 requires PHP 8.0; updater 2.1.0 requires PHP 8.1. Components pause on an unsupported platform while host navigation/settings remain usable; manual updates remain possible. A newer compatible Library may win election when another host is present. An incompatible older shared updater class is handled with a settings notice.

QuickNav can activate without Breakdance and keeps settings available. Its scoped activation adapter delegates other plugins to the unchanged Library guard. Library 0.8.1's central catalog still describes the previously published Breakdance QuickNav; discovery cards are not rewritten by this host. Updating that catalog is a separate task after an approved stable release.

Artwork B is selected. Deeper checks of the four unsupplied addons follow this test version. The navigation-only snippet is separately generated under the explicit project approval. It has no settings page, updater or Library and must not run beside the plugin.
